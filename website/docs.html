Installation

Install clairvoy globally from npm:

terminal
$ npm install -g clairvoy

Requirements: Node.js >= 20. Works on macOS, Linux, and Windows.

Permission error? Run sudo npm install -g clairvoy

Quick Start

No configuration needed. clairvoy reads your existing Claude Code session logs automatically.

terminal
# Quick scan (no args = instant overview)
$ clairvoy

# Deep cost analysis
$ clairvoy analyze

# Instant optimization (top 3 rules)
$ clairvoy quickfix

# Full optimization (22 rules)
$ clairvoy optimize --install

# Real-time protection with $10 budget
$ clairvoy guard --budget 10

How It Works

Claude Code writes JSONL session logs to ~/.claude/projects/. clairvoy reads these logs, classifies token usage, detects waste patterns, and generates optimization rules.

No API keys. No config. Works offline. 100% local.

Privacy: clairvoy never transmits your data anywhere. Everything runs on your machine.

Deep cost breakdown with token attribution, compounding analysis, behavioral pattern detection, and model routing recommendations.

Options

OptionDescription
--jsonOutput as JSON
-a, --allAnalyze all recent sessions

What it shows

  • Cost Breakdown — cache read/write/output/input with dollar amounts
  • Who Caused What — tokens from you, Claude, system, history retransmission
  • Context Growth — how context grew from turn 1 to last
  • Output Breakdown — code, text, sycophancy, suggestions, meta-commentary, echoing, re-reads
  • Waste Detected — file re-reads, filler, verbose output
  • Behavioral Patterns — loops, dead-ends, retry storms, search spirals, yak-shaves, tool call spam
  • Model Routing new — which turns could have used a cheaper model

clairvoy optimize

clairvoy optimize [options]

Analyzes your recent sessions and generates a CLAUDE.md with rules targeted to your waste patterns. 22 rules in the catalog, each with measured savings and break-even analysis.

Options

OptionDescription
--dry-runPreview rules without writing
--installWrite CLAUDE.md + track for adaptation
--adaptCompare before/after, refine rules
--writeWith --adapt, update the file
-n, --limit <number>Sessions to analyze (default 15)
-o, --output <path>Output path

Recommended workflow

terminal
# Preview
$ clairvoy optimize --dry-run

# Install + track
$ clairvoy optimize --install

# Code for a few sessions, then adapt
$ clairvoy optimize --adapt

clairvoy guard / unguard

clairvoy guard [options]clairvoy unguard

Install real-time PostToolUse hooks into Claude Code. Warnings appear inside Claude Code's context, so Claude itself sees them and adjusts behavior.

Options

OptionDescription
--dry-runPreview without installing
--budget <dollars>Set session budget cap new

What guard watches for

  • Context exceeds 150K tokens
  • File re-read 3+ times
  • Session cost approaching threshold
  • Turn count exceeds 50
  • Budget cap exceeded new

Budget Caps new

Set a dollar cap per session. Guard warns at 80% usage and gives a hard warning when exceeded.

terminal
# Install guard with $10 budget
$ clairvoy guard --budget 10

# During your session, you'll see:
[clairvoy] Budget 80% used — $8.00 of $10.00 cap
[clairvoy] BUDGET EXCEEDED — $12.40 spent (over by $2.40)

Budget is persisted in ~/.clairvoy/config.json and survives across sessions.

clairvoy pulse

clairvoy pulse Hidden from --help (hook handler)

Called automatically by guard hooks after every tool call. Outputs a compact status line:

output
[clairvoy] $4.20 | 23 turns | 150K ctx | 3 re-reads | budget: 80%

Must complete in <100ms. Uses incremental parsing to avoid re-reading entire session files.

CLAUDE.md Rules

clairvoy optimize selects from a catalog of 22 rules based on your detected waste patterns. Each rule has estimated savings and break-even turns.

Rule categories

CategoryRulesExamples
Output reduction8No sycophancy, no trailing summaries, no code echoing, no option lists
Tool efficiency6Track file reads, targeted reads, grep before read, batch operations
Behavioral6Stop before looping, compact early, plan before coding, narrow search first
Prompt quality2Include file paths, paste exact errors
Rule cost: ~324 tokens/turn. Pay for themselves in 2-5 turns based on eliminated waste.

After clairvoy analyze, the output now includes model routing recommendations. It identifies turns that were "simple" enough for a cheaper model.

FAQ

Does clairvoy send my data anywhere?

No. 100% local. It reads ~/.claude/projects/ and never transmits anything.

Does it work with all Claude Code plans?

Yes — Free, Pro, Max, and API. Cost numbers shown are API-equivalent pricing.

Will it slow down Claude Code?

The guard hook targets <100ms per tool call. It uses incremental parsing (only reads new bytes since last check) to stay fast. You won't notice it during normal use.

How accurate are the token counts?

Cost numbers are exact — they come from the API usage fields in Claude's session logs. Waste category breakdowns are estimates — the classifier uses a ~4 characters/token heuristic to categorize output tokens into sycophancy, meta-commentary, etc. The total cost is precise; the per-category split is approximate.

What do the dollar amounts mean on Max/Pro plans?

The costs shown are API-equivalent pricing — what your tokens would cost at Anthropic's pay-per-token rates. On Max/Pro, you're not billed per token, but these numbers tell you how efficiently you're using your allowance. Higher costs = faster rate limit hits.

Does it work on Windows?

It should work on Windows with Node.js >= 20. Terminal colors work best on Windows Terminal or VS Code terminal. The live command uses fs.watch which may behave slightly differently on Windows.

Can I use it with Cursor or other tools?

Currently Claude Code only. Other tool support may come in the future.

How is this different from ccusage?

ccusage shows you what you spent. clairvoy tells you how to spend less — it generates CLAUDE.md rules, installs guard hooks, coaches your prompts, and measures whether the optimization actually worked.
