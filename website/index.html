What it does

Four commands that
actually save money.

Not another usage tracker. clairvoy tells you how to spend less.

opt
optimize
Generates a CLAUDE.md from YOUR actual waste patterns. 22 rules, each with measured savings and break-even analysis. --adapt refines it over time.
clairvoy optimize --install
grd
guard
Installs PostToolUse hooks into Claude Code. Warns you in real-time when context grows large, files are re-read, or costs spike. Prevents waste while you code.
clairvoy guard
doc
doctor
Scans 20 sessions, finds systemic problems: long sessions, no CLAUDE.md, file re-read patterns, high tool call counts. Gives prescriptions with effort estimates.
clairvoy doctor
cch
coach
Scores your prompts by specificity (0-100) and shows cost correlation. Prompts with file paths cost 75% less. Prompts with line numbers cost 89% less.
clairvoy coach

How it works

Three commands. That's it.

Reads your existing Claude Code session logs. No config, no API keys, works offline.

01
Install
One command. Works with all your existing sessions immediately.
npm install -g clairvoy
02
Diagnose
Scans your sessions and shows exactly where the waste is.
clairvoy doctor
03
Fix
Generates and installs a CLAUDE.md tuned to your patterns.
clairvoy optimize --install
Get started

30 seconds to your first insight.

terminal 
# Install globally
$ npm install -g clairvoy

# See your sessions
$ clairvoy list

# Deep cost analysis
$ clairvoy analyze

# Find systemic waste
$ clairvoy doctor

# Generate + install optimized CLAUDE.md
$ clairvoy optimize --install

# Enable real-time protection
$ clairvoy guard
